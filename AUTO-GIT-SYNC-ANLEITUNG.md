## Übersicht

**Auto Git Sync** ist ein automatisches System, das erkennt, wenn Auto Claude Tasks auf "Done" gesetzt werden, und dann automatisch Git-Operationen ausführt.

### Was macht es?

✅ **Erkennt** automatisch wenn Tasks fertig sind (Status = "done")  
✅ **Committet** Änderungen mit aussagekräftiger Message  
✅ **Pusht** optional zu GitHub  
✅ **Erstellt** optional Pull Requests  
✅ **Synchronisiert** bidirektional mit Auto Claude UI  

### Warum brauchst du es?

**Vorher (Manuell):**
```
1. Auto Claude beendet Task
2. Du merkst nicht sofort dass Task fertig ist
3. Du musst manuell commiten
4. Du musst manuell pushen
5. Du musst manuell PR erstellen
```

**Nachher (Automatisch):**
```
1. Auto Claude beendet Task
2. Auto Git Sync erkennt das sofort
3. Committet automatisch
4. Pusht automatisch (optional)
5. Erstellt PR automatisch (optional)
```

**Zeitersparnis:** 5-10 Minuten pro Task! ⚡

## Installation

### Schritt 1: Python-Abhängigkeiten (bereits installiert)

Das Script nutzt nur Python Standard-Bibliotheken:
- `json`
- `subprocess`
- `pathlib`
- `argparse`

Keine zusätzlichen Pakete erforderlich! ✅

### Schritt 2: Desktop-Verknüpfungen erstellen

```powershell
# Im Projekt-Verzeichnis
.\Create-GitSync-Shortcut.ps1
```

Das erstellt 4 Verknüpfungen auf deinem Desktop:

1. **Auto Git Sync.lnk**  
   → Nur Committen (sicher für Tests)

2. **Auto Git Sync + Push.lnk**  
   → Committen + Pushen (empfohlen für Production)

3. **Auto Git Sync + PR.lnk**  
   → Volle Automation (benötigt `gh` CLI)

4. **Git Sync Check.lnk**  
   → Einmalige Prüfung + Push

### Schritt 3: GitHub CLI (Optional, für PR-Erstellung)

Wenn du automatische Pull Requests willst:

```powershell
# Installieren
winget install GitHub.cli

# Authentifizieren
gh auth login
```

## Verwendung

### Option 1: Desktop-Verknüpfung (Einfachste Methode) 🖱️

1. **Doppelklick** auf `Auto Git Sync + Push.lnk`
2. Terminal öffnet sich und zeigt:
   ```
   ============================================
   Auto Git Sync - Watch Mode
   ============================================
   
   [INFO] Überwache: C:\Projekte\auto-claude\.auto-claude\specs
   [INFO] Auto-Push: AKTIV
   [INFO] Auto-PR: INAKTIV
   
   [INFO] Drücken Sie Ctrl+C zum Beenden
   ```
3. **Minimiere das Fenster** (läuft im Hintergrund)
4. **Arbeite normal** mit Auto Claude
5. **Fertig!** Auto Git Sync macht den Rest

### Option 2: Terminal-Befehle (Fortgeschritten) 💻

```bash
# Watch Mode (nur committen)
python apps\backend\auto_git_sync.py --watch

# Watch Mode + Auto-Push (empfohlen)
python apps\backend\auto_git_sync.py --watch --auto-push

# Watch Mode + Auto-Push + PR (volle Automation)
python apps\backend\auto_git_sync.py --watch --auto-push --create-pr

# Einmalige Prüfung
python apps\backend\auto_git_sync.py --check-done --auto-push

# Nur einen Spec überwachen
python apps\backend\auto_git_sync.py --watch --spec 001
```

## Modi

### 1. Watch Mode (Kontinuierlich)

**Zweck:** Läuft im Hintergrund und überwacht kontinuierlich

**Verwendung:**
```bash
python apps\backend\auto_git_sync.py --watch
```

**Verhalten:**
- Prüft alle **5 Sekunden** auf neue Done Tasks
- Läuft **unbegrenzt** bis Ctrl+C
- Verarbeitet jeden Task **nur einmal**
- Zeigt alle 10 Checks eine Status-Nachricht

**Output:**
```
============================================
Auto Git Sync - Watch Mode
============================================

[INFO] Überwache: .auto-claude\specs
[INFO] Auto-Push: INAKTIV
[INFO] Auto-PR: INAKTIV

[15:30:00] Keine neuen Done Tasks... (Check #1)
[15:30:10] Keine neuen Done Tasks... (Check #2)

[OK] 1 neue Done Tasks gefunden!

============================================
Git Commit für Task: 001-user-auth
============================================
Feature: User Authentication System

[OK] Änderungen gefunden:
M  apps/backend/auth.py
M  apps/frontend/login.tsx

[INFO] Stage alle Änderungen...
[INFO] Erstelle Commit:

feat(auto-claude): User Authentication System

Auto Claude Task: 001-user-auth
Subtasks completed: 5/5
Status: DONE ✅

Generated by: Auto Git Sync
Timestamp: 2025-12-30T15:30:15

[OK] Commit erfolgreich erstellt!
[OK] Task 001-user-auth erfolgreich verarbeitet!
```

### 2. Check Mode (Einmalig)

**Zweck:** Einmalige Prüfung, dann beenden

**Verwendung:**
```bash
python apps\backend\auto_git_sync.py --check-done
```

**Verhalten:**
- Prüft **einmal**
- Verarbeitet alle gefundenen Done Tasks
- **Beendet sich** danach

**Wann verwenden:**
- Nach manueller Task-Fertigstellung
- Wenn Watch Mode nicht läuft
- Für Skript-Integration (CI/CD)

### 3. Auto-Push Mode

**Zweck:** Pusht automatisch zu GitHub

**Verwendung:**
```bash
python apps\backend\auto_git_sync.py --watch --auto-push
```

**WICHTIG:**
- Pusht zu deinem konfigurierten Remote (`origin`)
- Nutzt aktuellen Branch
- **Standardmäßig DEAKTIVIERT** (Sicherheit!)

**Empfehlung:**
- ✅ Nutze `--auto-push` in Production
- ❌ NICHT nutzen beim Testen

### 4. Auto-PR Mode

**Zweck:** Erstellt automatisch Pull Requests

**Verwendung:**
```bash
python apps\backend\auto_git_sync.py --watch --auto-push --create-pr
```

**Voraussetzungen:**
1. GitHub CLI installiert (`gh`)
2. Authentifiziert (`gh auth login`)
3. Remote auf GitHub

**PR-Format:**
```
Title: feat: User Authentication System

Body:
Auto Claude Task: 001-user-auth

User Authentication System

Generated by: Auto Git Sync
```

## Workflow-Beispiele

### Scenario 1: Entwicklung (Sicher) 🛡️

**Situation:** Du testest Auto Claude und willst nicht versehentlich pushen.

**Lösung:**
1. Starte Watch Mode **ohne** `--auto-push`:
   ```bash
   python apps\backend\auto_git_sync.py --watch
   ```

2. Arbeite mit Auto Claude wie gewohnt

3. Tasks werden automatisch **committet** aber **NICHT gepusht**

4. Prüfe Commits:
   ```bash
   git log --oneline -5
   ```

5. Push manuell wenn zufrieden:
   ```bash
   git push origin main
   ```

### Scenario 2: Production (Vollautomatisch) 🚀

**Situation:** Du willst maximale Automation für produktiven Code.

**Lösung:**
1. Starte vollautomatischen Modus:
   ```bash
   python apps\backend\auto_git_sync.py --watch --auto-push --create-pr
   ```

2. Arbeite mit Auto Claude

3. Tasks werden automatisch:
   - Committet ✅
   - Gepusht ✅
   - PR erstellt ✅

4. Du musst nur noch:
   - PR reviewen
   - Mergen

### Scenario 3: Specific Task (Gezielt) 🎯

**Situation:** Du willst nur einen bestimmten Task automatisieren.

**Lösung:**
```bash
python apps\backend\auto_git_sync.py --watch --spec 001-user-auth --auto-push
```

Überwacht nur `001-user-auth` und committet/pusht nur diesen Task.

### Scenario 4: Multi-Task Batch (Stapelverarbeitung) 📦

**Situation:** Mehrere Tasks sind fertig und du willst alle auf einmal verarbeiten.

**Lösung:**
```bash
python apps\backend\auto_git_sync.py --check-done --auto-push
```

Verarbeitet alle Done Tasks auf einmal und beendet sich dann.

## Fehlerbehebung

### Problem 1: "Keine Done Tasks gefunden" ❌

**Symptome:**
```
[INFO] Keine neuen Done Tasks gefunden
```

**Diagnose:**

1. **Prüfe Status in implementation_plan.json:**
   ```bash
   type .auto-claude\specs\001-feature\implementation_plan.json | findstr "status"
   ```
   
   **Erwartete Ausgabe:**
   ```json
   "status": "done",
   "planStatus": "completed"
   ```

2. **Prüfe ob bereits verarbeitet:**
   ```bash
   type .auto-claude\git_sync_state.json
   ```
   
   **Wenn der Task darin steht:** Er wurde bereits verarbeitet!

**Lösung:**

**Option A:** Reset State (alle Tasks neu verarbeiten)
```bash
python apps\backend\auto_git_sync.py --reset-state
python apps\backend\auto_git_sync.py --check-done
```

**Option B:** Task-Status direkt ändern
```json
// In implementation_plan.json
{
  "status": "done",  // ← Stelle sicher dass es "done" ist
  "planStatus": "completed"
}
```

### Problem 2: "Push fehlgeschlagen" ❌

**Symptome:**
```
[ERROR] Push fehlgeschlagen: ...
```

**Diagnose:**

1. **Prüfe Git Remote:**
   ```bash
   git remote -v
   ```
   
   **Erwartete Ausgabe:**
   ```
   origin  https://github.com/user/repo.git (fetch)
   origin  https://github.com/user/repo.git (push)
   ```

2. **Prüfe Branch:**
   ```bash
   git branch --show-current
   ```

3. **Prüfe Git-Status:**
   ```bash
   git status
   ```

**Lösung:**

**Option A:** Kein Remote konfiguriert
```bash
git remote add origin https://github.com/user/repo.git
git push -u origin main
```

**Option B:** Authentifizierung fehlt
```bash
# GitHub CLI
gh auth login

# Oder Git Credentials
git config --global credential.helper manager
```

**Option C:** Branch existiert nicht auf Remote
```bash
git push -u origin main  # Erstellt Branch auf Remote
```

### Problem 3: "PR-Erstellung fehlgeschlagen" ❌

**Symptome:**
```
[WARN] GitHub CLI (gh) nicht gefunden
```

**Lösung:**

1. **Installiere GitHub CLI:**
   ```powershell
   winget install GitHub.cli
   ```

2. **Authentifiziere:**
   ```bash
   gh auth login
   ```
   
   Folge den Anweisungen im Terminal.

3. **Teste:**
   ```bash
   gh auth status
   ```
   
   **Erwartete Ausgabe:**
   ```
   ✓ Logged in to github.com as YourUsername
   ```

### Problem 4: "Commit schlägt fehl wegen Secrets" ❌

**Symptome:**
```
[ERROR] Git-Fehler: Secrets detected!
```

**Lösung:**

Auto Claude hat bereits Secret Scanning integriert. Wenn Commit fehlschlägt:

1. **Prüfe welche Secrets:**
   ```bash
   python apps\backend\diagnose.py --scan-secrets
   ```

2. **Move to .env:**
   ```python
   # BAD
   api_key = "sk-abc123..."
   
   # GOOD
   import os
   api_key = os.environ.get("API_KEY")
   ```

3. **Update .env.example:**
   ```
   API_KEY=your-api-key-here
   ```

4. **Retry Commit:**
   ```bash
   python apps\backend\auto_git_sync.py --check-done
   ```

**Production:**

**Terminal 1:**


```bash
python apps\backend\auto_git_sync.py --watch --auto-push
```

## FAQ

### F: Kann ich Auto Git Sync auf mehreren Branches gleichzeitig nutzen?

**A:** Ja! Starte für jeden Branch einen eigenen Prozess:

```bash
# Branch 1
git checkout feature-1
python apps\backend\auto_git_sync.py --watch &

# Branch 2
git checkout feature-2
python apps\backend\auto_git_sync.py --watch &
```

### F: Was passiert wenn ich einen Task manuell committe?

**A:** Auto Git Sync erkennt "keine Änderungen" und überspringt den Commit:

```
[INFO] Keine Änderungen zum Committen
[OK] Task 001-feature erfolgreich verarbeitet!
```

### F: Kann ich Auto Git Sync pausieren?

**A:** Ja! Drücke `Ctrl+C` im Terminal. Beim nächsten Start lädt es den gespeicherten State.

### F: Was ist wenn ich einen falschen Commit mache?

**A:** Rollback ist einfach:

```bash
# Letzte Commit rückgängig machen
git reset --soft HEAD~1

# Oder Hard-Reset (VORSICHT!)
git reset --hard HEAD~1
```

### F: Funktioniert es mit GitHub Enterprise?

**A:** Ja! Konfiguriere `gh` für deine Enterprise-Instanz:

```bash
gh auth login --hostname github.mycompany.com
```

### F: Kann ich benutzerdefinierte Commit-Hooks nutzen?

**A:** Ja! Auto Git Sync respektiert alle Git-Hooks (pre-commit, commit-msg, etc.)
