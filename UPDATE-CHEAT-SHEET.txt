┌───────────────────────────────────────────────────────────────┐
│ 🚀 HÄUFIGSTE BEFEHLE                                          │
└───────────────────────────────────────────────────────────────┘

  Status prüfen:
    git status
  
  Änderungen speichern:
    git add -A
    git commit -m "Meine Änderungen"
    git push origin develop
  
  Updates prüfen (ohne zu holen):
    git fetch upstream
    git log develop..upstream/develop
  
  Letzte Commits ansehen:
    git log --oneline -10

┌───────────────────────────────────────────────────────────────┐
│ ⚠️ MERGE-KONFLIKT LÖSEN                                       │
└───────────────────────────────────────────────────────────────┘

  1. Öffne Datei in Editor
  2. Suche nach: <<<<<<< HEAD
  3. Zwischen <<< und === = Dein Code
  4. Zwischen === und >>> = Original Code
  5. Entscheide welche Version (oder beide)
  6. Lösche Marker (<<<, ===, >>>)
  7. Speichern
  8. git add .
  9. git commit -m "Konflikt gelöst"
  10. git push origin develop

┌───────────────────────────────────────────────────────────────┐
│ 🆘 NOTFALL-BEFEHLE                                            │
└───────────────────────────────────────────────────────────────┘

  Letzten Merge rückgängig:
    git reset --hard HEAD^
  
  Zurück zum letzten Stand:
    git reset --hard origin/develop
  
  Alle Änderungen verwerfen:
    git checkout -- .
    git clean -fd
