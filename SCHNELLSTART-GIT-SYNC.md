# 🚀 Auto Git Sync - Schnellstart

## In 3 Minuten zum automatischen Git Workflow!

### Schritt 1: Desktop-Verknüpfungen erstellen (30 Sekunden)

```powershell
# Im Projekt-Verzeichnis (c:\Projekte\auto-claude)
.\Create-GitSync-Shortcut.ps1
```

**Was passiert:**
- Erstellt 4 Desktop-Verknüpfungen
- Konfiguriert alle Modi (Watch, Push, PR)
- Fertig in 5 Sekunden! ✅

### Schritt 2: Ersten Test durchführen (1 Minute)

**Option A: Sicherer Test (nur committen)**

1. Doppelklick auf `Auto Git Sync.lnk` auf dem Desktop
2. Terminal öffnet sich und zeigt:
   ```
   Auto Git Sync - Watch Mode
   [INFO] Überwache: .auto-claude\specs
   [INFO] Auto-Push: INAKTIV
   ```
3. Minimiere das Fenster
4. **Fertig!** Läuft jetzt im Hintergrund

**Option B: Vollautomatisch (committen + pushen)**

1. Doppelklick auf `Auto Git Sync + Push.lnk`
2. Terminal zeigt:
   ```
   Auto Git Sync - Watch Mode
   [INFO] Auto-Push: AKTIV
   ```
3. Minimiere das Fenster
4. **Fertig!** Committet UND pusht automatisch

### Schritt 3: Arbeiten wie gewohnt! (∞)

1. **Nutze Auto Claude normal**
   - Erstelle Tasks
   - Lasse AI implementieren
   - Tasks werden auf "Done" gesetzt

2. **Auto Git Sync macht den Rest!**
   - Erkennt "Done" Status (alle 5 Sekunden)
   - Erstellt automatisch Commit
   - Pusht zu GitHub (wenn aktiviert)
   - Zeigt Bestätigung:
     ```
     [OK] Task 001-feature erfolgreich verarbeitet!
     ```

3. **Das war's!** 🎉

## Häufige Fragen

### F: Muss ich Auto Git Sync für jeden Task neu starten?

**A:** NEIN! Einmal starten, läuft unbegrenzt. Überwacht ALLE Tasks automatisch.

### F: Was wenn ich einen Task manuell committe?

**A:** Kein Problem! Auto Git Sync erkennt "keine Änderungen" und überspringt den Commit.

### F: Kann ich es wieder stoppen?

**A:** Ja! Drücke `Ctrl+C` im Terminal oder schließe das Fenster.

### F: Wo sehe ich was Auto Git Sync macht?

**A:** Im Terminal-Fenster (nicht minimieren wenn du zuschauen willst) ODER:

```bash
# In separatem Terminal
python apps\backend\live_monitor.py --follow-all
```

### F: Was wenn etwas schiefgeht?

**A:** Siehe vollständige Anleitung: `AUTO-GIT-SYNC-ANLEITUNG.md`
